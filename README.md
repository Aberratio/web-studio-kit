# web-studio-kit

Shared building blocks for custom, 3D-heavy client websites: React Three Fiber scenes, GLSL shaders, post-processing effects, GSAP animation helpers and smooth scrolling.

Client sites install a pinned version straight from GitHub:

```sh
npm install github:aberratio/web-studio-kit#v0.1.0
```

## Stack

- React, TypeScript
- three.js, @react-three/fiber, @react-three/drei
- postprocessing, custom GLSL
- GSAP, Lenis

All dependencies are free and open source. No paid libraries.
